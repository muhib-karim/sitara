# Sitara identity

The split star is an original Sitara drawing. A diagonal opening cuts through four unequal rays; the same two paths work in saffron or in one monochrome fill. The 108-unit adaptive foreground stays inside the launcher's 66-unit safe circle. The master SVG includes a neutral rounded preview background; Android supplies the system mask.

## Typography provenance
Bundled fonts are static instances of the official Inter 4.001 variable font (embedded version `4.001;git-66647c0bb`, project https://github.com/rsms/inter). Body instances use optical size 14 at weights 400/500/600/700; display instances use optical size 32 at 700/800. The original font's embedded copyright and OFL metadata are preserved. Official download: https://rsms.me/inter/ . See OFL.txt.

No reference-app font, image, logo or source file is shipped.
